# Productivity

General workflow tools, not code-specific.

## User-invoked

Reachable only when you type them (`disable-model-invocation: true`).

- **[grill-me](./grill-me/SKILL.md)**: get relentlessly interviewed about a plan or design until every branch of the design tree is resolved. Hands off to `grilling`.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[grilling](./grilling/SKILL.md)**: interview the user relentlessly about a plan, decision, or idea, a round of numbered questions at a time, each with a recommended answer, until every branch of the design tree is resolved. The reusable interview primitive behind `grill-me`.

`grill-me` and `grilling` come from [mattpocock/skills](https://github.com/mattpocock/skills) (MIT, commit `d6539114`); each keeps the upstream `LICENSE` beside its `SKILL.md`.
